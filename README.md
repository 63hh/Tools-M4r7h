تنبيه وإخلاء مسؤولية قانونية

هذا المستودع مخصص لأغراض تجريبية وتعليمية فقط. نحن نوفر الأدوات والملفات كما هي، ولا نتحمل أي مسؤولية قانونية أو جنائية أو أخلاقية عن أي استخدام خاطئ، أو ضرر يلحق بجهازك، أو أي نشاط غير قانوني يتم القيام به باستخدام هذه الأدوات. 

تحميلك وتشغيلك للملفات المطروحة هنا تقع تحت مسؤوليتك الشخصية والكاملة، ونحن غير مسؤولين عن أي تصرف أو عواقب تنتج عن ذلك بعد خروج الملف من هذا المستودع.
